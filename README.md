## Setting up the environment

In order to directly run the scripts you have to set up a conda environment with Python 3.10.
In the highest level of the repository you will find a requirements.txt.
Please install the requirements in your newly created environment.

## Project structure

There are 3 main folders:
* pacman
* snake
* pacman_and_snake

Each of these folders is divided into q-learning and ppo. Inside these folders you will find the python scripts for training together with a README where it is explained how to start the scripts and with which parameters.
